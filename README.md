# Real Estate Web App

This is a full-stack real estate listing web application that allows users to browse, list, and manage properties. It features a modern UI, 
user authentication, image uploads, and dynamic property search capabilities. The frontend is built with React, Redux Toolkit, and Tailwind CSS, 
while the backend uses Express, Node.js, and MongoDB. Authentication is handled via Firebase and JWT.

## Live Demo

[View the Live Application](https://realestate-yied.onrender.com/)

## Features

- User authentication (Firebase and JWT)
- Create, update, and delete property listings
- Browse and filter properties for sale or rent
- Responsive and mobile-friendly design
- Protected routes for authorized users
- RESTful API integration
- Image uploads with cloud storage

## Getting Started

Follow these steps to run the project locally:

1. Clone the repository:
   git clone https://github.com/Ashbipbinu/realestate.git

2. Navigate to the project directory:
   cd realestate
   
3. Install frontend dependencies:
   cd frontend npm install

4. Install backend dependencies:
   cd ../server npm install

5. Set up environment variables:
Create a `.env` file and add your configuration for:
- MongoDB URI
- Firebase API keys
- JWT secret

6. Run the application:
- Start backend server:
  ```
  npm run dev
  ```
- Start frontend app:
  ```
  cd ../client
  npm start
  ```
